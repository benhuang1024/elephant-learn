PHP 架构师的对照

Laravel 的 FormRequest::validate() / Symfony 的 Validator 是运行时校验；PHPStan / Psalm 是静态检查。两者各司其职。

TS 把「静态检查」做到了语言里，但没有自带运行时校验。所以 body as PlaceOrderRequest 只是一句谎言：编译器信了，运行时什么都没有。Zod 就是补上 FormRequest 那一半。

一处定义，四端复用

schema 是运行时的值，类型从它推导：type X = z.infer<typeof S>。服务端 Pipe 用它校验，前端表单用它解析响应，契约测试用它断言形状——改一处，四端一起变。

这就是第 14 章 monorepo 里 @shop/shared 的存在理由：不是「共享工具函数」，是共享契约。

为什么金额不用 number

0.1 + 0.2 !== 0.3 与 PHP float 同源；更隐蔽的是 JSON.stringify(599.00) === "599"——数字字面量没有「几位小数」。

仓库方案：DTO 层品牌字符串 "599.00"，运算全走整数分，出口才写回 JSON 数字。语义等价、字面差异被关在两个函数里。
