| 名称 | 用途 | 链接 |

## 书籍

- 《The Web Application Hacker's Handbook》：Web 测试经典，部分内容较老，适合理解原理
- 《Real-World Bug Hunting》（Peter Yaworski）：真实漏洞案例
- 《Security Engineering》（Ross Anderson）：安全工程全景，第三版作者官网可免费阅读
- 《Serious Cryptography》（Jean-Philippe Aumasson）：面向工程师的密码学
- 《Alice and Bob Learn Application Security》（Tanya Janca）：安全开发入门
- 《Hacking Kubernetes》（Andrew Martin, Michael Hausenblas）：K8s 威胁模型与防御
