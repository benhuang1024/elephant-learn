## 推荐学习路径

### 第一遍：建立框架（1 周）
1. 精读 01，理解"甲方关系的本质是**降低甲方对接人的风险**"。
2. 通读 02、04、05，每章挑出 3 个你最有共鸣的技巧，抄到笔记里。
3. 把 08 话术库里你**最常遇到的 3 个场景**的话术大声读 10 遍。

### 第二遍：刻意练习（8 周）
按 [10-刻意练习与复盘](10-刻意练习与复盘.md) 的周计划，每周一个主题：
- 每天做 1 道 09 里的演练题（先自己写答案，再看参考）
- 每周在真实工作中**至少用一次**本周主题的技巧
- 每周五用模板做一次复盘

### 第三遍：形成自己的体系（持续）
- 把你自己的真实案例补充到 09 里（脱敏）
- 把你说过的"效果很好的一句话"补充到 08 里
- 每季度用 10 里的自评量表打一次分，看哪项最弱

## 核心心法（先记住这 10 句）

1. **甲方对接人首先是一个要对上级负责的人**。帮他在领导面前有面子、不背锅，他就会帮你。
2. **不要带着问题去，要带着选项去**。"有 A/B/C 三个方案，我建议 B，原因是……"
3. **坏消息要早说、主动说、带着方案说**。坏消息不会因为晚说而变好，只会变成"隐瞒"。
4. **所有口头约定，24 小时内落到书面**。会议纪要是乙方最便宜的保险。
5. **先处理情绪，再处理事情**。对方在气头上时讲道理等于火上浇油。
6. **说"可以，但是……"而不是"不行"**。用代价替代拒绝：可以加，但要延期 2 周或加 1 个人。
7. **资源不是要来的，是换来的**。想清楚对方要什么，你能给什么。
8. **突发事件的第一原则：先止血，再定责，最后复盘**。
9. **期望管理大于结果交付**。交付 80 分但承诺 70 分，是惊喜；交付 90 分但承诺 100 分，是失望。
10. **关系是在不需要求人的时候建立的**。平时多一次主动同步，关键时刻少一次被动解释。

## 术语约定

| 术语 | 含义 |
|---|---|
| 甲方 | 项目的客户方 / 出资方 / 需求方 |
| 乙方 | 承接项目的服务方 / 交付方（本手册的"我们"） |
| 对接人 | 甲方日常对接的项目经理或业务负责人 |
| 决策人 | 甲方真正拍板的人（往往不是对接人） |
| 干系人 | 所有会影响项目或被项目影响的人 |
| 范围蔓延 | 需求在没有正式变更的情况下不断扩大 |
| 升级 | 把问题提交到更高层级去决策 |
