# 01 角色认知与沟通底层逻辑

> 技巧是"术"，认知是"道"。很多沟通失败不是话没说好，而是没想清楚对方要什么、自己是什么角色。

---

## 1. 乙方到底在"卖"什么？

表面上乙方卖的是：系统、代码、方案、人天。
本质上乙方卖的是：**确定性**。

甲方花钱请乙方，核心诉求是：
- 把一件**他们自己做不了 / 不想做 / 做不快**的事情做成；
- 而且过程中**不要出幺蛾子**，不要让他们在领导面前难堪。

所以乙方的价值 = **专业能力 × 可预期性 × 让甲方省心的程度**。

> 一个技术很强但经常"突然告诉甲方延期"的乙方，往往不如一个技术一般但"每周主动同步、风险提前预警"的乙方受欢迎。

---

## 2. 甲方不是一个人，是一张网

### 2.1 甲方典型角色

| 角色 | 典型职位 | 他最关心什么 | 他最怕什么 | 和他沟通的要点 |
|---|---|---|---|---|
| 决策人 | 分管领导、CIO、业务 VP | 业务价值、政绩、ROI、是否符合战略 | 项目失败、被上级问责、花钱没效果 | 讲结果、讲价值、讲风险可控；时间短、结论先行 |
| 对接人 / 项目经理 | 甲方 PM、IT 主管 | 按时上线、不出事、向领导好交代 | 背锅、被领导批评、夹在中间 | 让他有面子、给他"弹药"去汇报、不越级（除非必要） |
| 业务用户 | 一线业务人员、科室人员 | 好不好用、会不会增加工作量 | 系统难用、改变习惯、出错被追责 | 讲操作便利、做好培训、尊重他们的经验 |
| 技术把关人 | 甲方架构师、运维、安全 | 技术规范、安全合规、可维护性 | 引入风险、以后出问题要他兜底 | 讲技术细节、文档齐全、尊重其规范 |
| 采购 / 财务 | 采购部、财务部 | 合规、价格、付款节点 | 违规、审计出问题 | 材料齐全、流程合规、不要催得太急但要持续跟 |
| 隐形影响者 | 领导秘书、老员工、竞品的"朋友" | 各有不同 | 各有不同 | 先识别，再判断是盟友还是阻力 |

### 2.2 画一张干系人地图（每个项目开始都要做）

用"**权力-利益**"四象限：

```
           高权力
              │
   重点满足    │   重点管理（核心）
  (领导、审计)  │  (决策人、对接人)
──────────────┼──────────────
   持续关注    │   随时告知
  (边缘部门)   │  (业务用户、技术人员)
              │
           低权力
  低利益 ◄────────────► 高利益
```

再给每个人标注**态度**：支持 / 中立 / 反对 / 未知。

**训练动作**：拿你当前项目，列出甲方所有你知道的人，填下表：

| 姓名 | 职位 | 权力(高/中/低) | 利益相关度 | 态度 | 他的核心诉求 | 我的策略 |
|---|---|---|---|---|---|---|
| | | | | | | |

> 如果你发现"决策人"一栏填不出来，或者"态度"大多是"未知"——这就是你下一步要补的课。

## 3. 信任从哪里来：信任公式

经典的信任公式（Maister）：

```
         可信度 × 可靠性 × 亲密度
信任 = ─────────────────────────
              自我导向
```

| 因子 | 含义 | 乙方怎么提升 |
|---|---|---|
| 可信度 Credibility | 你说的话靠不靠谱、专不专业 | 讲话有数据、有依据；不懂的不乱说，说"我确认后回复您" |
| 可靠性 Reliability | 你说到能不能做到 | 小承诺准时兑现（"下午 3 点前给您"就 2:50 给）；不轻易承诺 |
| 亲密度 Intimacy | 对方愿不愿意跟你说真话 | 保守秘密、站在他角度想、偶尔聊工作以外的事 |
| 自我导向 Self-orientation | 你是不是只顾自己 | 越低越好。少说"我们公司规定"，多说"这样对您有什么好处" |

**最容易被忽视的是"可靠性"**：信任主要靠大量**小承诺的兑现**积累，而不是一次大交付。

**训练动作**：本周给甲方做 5 个小承诺（"明早 10 点前发您纪要"），每个都提前兑现，记录对方反应。

## 4. 甲乙方关系的几个真相

1. **甲方对接人和你是"战友"，不是"敌人"**。他也需要项目成功，他的 KPI 和你的回款挂在同一条船上。你要做的是让他成为**你在甲方内部的代言人**。
2. **甲方的需求经常是模糊的，这不是他的错**。业务人员不懂技术，描述不清很正常。把模糊需求变清晰，本来就是乙方的专业价值。
3. **甲方说"随便""你们看着办"，往往不是真的随便**。是他还没想清楚，或者不想负责。这时一定要给出具体方案让他确认，并留痕。
4. **甲方领导一句话，可能推翻三个月的工作**。所以要尽早让领导参与关键评审，而不是最后才给他看。
5. **甲方的"急"有真急和假急**。真急：有上级考核节点、有外部检查。假急：习惯性催。学会问"这个时间点是因为什么？"
6. **合同是底线，关系是上限**。合同保证你不吃大亏，关系决定你能不能拿到续约、口碑和回款速度。
7. **付款节点是甲方最大的筹码，验收是乙方最大的关口**。整个项目的沟通都要为"顺利验收"服务。

## 5. 沟通的底层原则

### 5.1 结论先行（金字塔原理）

**错误示范**：
> "王经理，我们这周遇到了一些问题，第三方接口那边文档有问题，然后我们联系了他们，他们说要下周才能处理，然后测试环境也不太稳定，所以……可能上线要往后推一下。"

**推荐说法**：
> "王经理，结论先说：上线可能要从 15 号推迟到 22 号。主要原因有两个：一是第三方接口文档有误，对方下周才能修复；二是测试环境不稳定。我们准备了两个方案，想请您定一下……"

结构：**结论 → 原因（不超过 3 条）→ 方案/需要对方做什么**。

### 5.2 SCQA 开场法（适合汇报、说服）

- **S 情境 Situation**：大家都认可的背景（"目前系统日均访问量 10 万"）
- **C 冲突 Complication**：出现了什么变化或问题（"但月底促销预计会到 50 万，现有架构撑不住"）
- **Q 疑问 Question**：因此要解决什么问题（"怎么在两周内保证促销期间系统稳定？"）
- **A 答案 Answer**：你的方案（"建议做三件事：扩容、加缓存、限流"）

### 5.3 对事不对人

- ❌ "你们的需求一直在变" → ✅ "这个月需求有 12 处调整，我们一起看看怎么控制一下节奏"
- ❌ "你们的测试太慢了" → ✅ "测试这边如果能在周三前给反馈，我们周五就能修完"

### 5.4 说"我们"而不是"你们/我们公司"

把双方放在同一阵营：
- ❌ "你们那边接口还没给"
- ✅ "咱们这边还差一个接口，看看怎么推动一下"

### 5.5 可视化 > 文字 > 口头

能画图就不要写字，能写字就不要只是口头说。
- 进度：甘特图 / 里程碑图
- 问题：问题清单表格（编号、描述、责任人、截止时间、状态）
- 方案对比：对比表

### 5.6 确认理解（复述）

每次重要沟通结束前：
> "我复述一下我理解的，您看对不对：第一……第二……第三……。对的话我会后整理纪要发您确认。"

这一句话能避免 50% 以上的"我不是这个意思"。

## 6. 乙方常见的沟通误区

| 误区 | 表现 | 后果 | 正确做法 |
|---|---|---|---|
| 报喜不报忧 | 风险憋着自己扛，到最后才说 | 信任崩塌，被认为隐瞒 | 风险提前报，带着应对方案报 |
| 无条件答应 | 甲方说什么都"好的没问题" | 范围蔓延，交付失败，最后还是得罪人 | "可以，但需要……" |
| 技术黑话 | 满嘴"微服务、熔断、灰度" | 甲方听不懂，觉得你在推卸 | 用业务语言翻译技术问题 |
| 只跟对接人沟通 | 从不接触决策人 | 最后领导一句话推翻 | 关键节点争取向领导汇报 |
| 越级告状 | 跟对接人不合就去找他领导 | 对接人彻底变成敌人 | 越级前先和对接人沟通，"一起去汇报" |
| 只口头不留痕 | 电话里说好了就算了 | 出事时说不清 | 24 小时内书面确认 |
| 情绪化 | 被甲方骂了就怼回去 / 冷处理 | 关系破裂 | 先接情绪，事后再谈事 |
| 把内部问题甩给甲方 | "我们公司人手不够""我们领导不批" | 甲方觉得你不专业 | 内部问题内部解决，对外统一口径 |
| 承诺太满 | "肯定没问题""保证上线" | 一旦失败，信用破产 | 用概率和条件表达："在 X 条件下，有把握在 Y 日前完成" |

## 7. 乙方的"角色修炼"

一个优秀的乙方，需要在不同时刻切换不同角色：

| 场景 | 角色 | 关键能力 |
|---|---|---|
| 需求调研 | **顾问** | 提问、挖掘真实需求、给专业建议 |
| 方案评审 | **专家** | 讲清原理、权衡利弊、敢于说"不建议" |
| 日常推进 | **管家** | 及时同步、细节到位、让对方省心 |
| 出现分歧 | **谈判者** | 守住底线、寻找共同利益、交换筹码 |
| 突发事件 | **消防员** | 冷静、快速止血、稳定情绪 |
| 汇报验收 | **导演** | 设计汇报节奏、突出亮点、引导结论 |
| 关系维护 | **朋友** | 真诚、保密、雪中送炭 |

**自检问题**：你最擅长哪个角色？最不擅长哪个？在 [10-刻意练习与复盘](10-刻意练习与复盘.md) 里有对应的自评量表。
