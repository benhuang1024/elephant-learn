## 1. 工具对照

| PHP | Java |
|---|---|
| PHPUnit | **JUnit 5/6 (Jupiter)** |
| PHPUnit assertions | **AssertJ**（流式断言，强烈推荐） |
| Mockery / Prophecy | **Mockito** |
| Laravel `RefreshDatabase` + SQLite | `@DataJpaTest`（事务回滚）+ **Testcontainers**（真实数据库） |
| `$this->getJson('/api/...')` | **MockMvc** / `RestTestClient` |
| `Http::fake()` | MockRestServiceServer / WireMock |
| Pest 数据集 | `@ParameterizedTest` |

`spring-boot-starter-test` 已包含 JUnit、AssertJ、Mockito、Spring Test。Spring Boot 4 中各技术的测试支持也拆成了独立模块，例如 `spring-boot-starter-webmvc-test`、`spring-boot-starter-data-jpa-test`。

## 2. 纯单元测试（最多、最快）

不启动 Spring，直接 `new`。构造器注入的回报就在这里：

```java
class ProductTest {

    @Test
    void 扣减库存成功() {
        var p = new Product("PHONE-1", "手机", new BigDecimal("1999.00"), 10);
        p.deduct(3);
        assertThat(p.getStock()).isEqualTo(7);
    }

    @Test
    void 库存不足抛业务异常() {
        var p = new Product("PHONE-1", "手机", new BigDecimal("1999.00"), 2);
        assertThatThrownBy(() -> p.deduct(5))
                .isInstanceOf(InsufficientStockException.class)
                .hasMessageContaining("库存不足");
    }

    @ParameterizedTest
    @CsvSource({"0, 10", "5, 5", "10, 0"})
    void 各种扣减数量(int qty, int expectedLeft) {
        var p = new Product("A", "a", BigDecimal.ONE, 10);
        p.deduct(qty);
        assertThat(p.getStock()).isEqualTo(expectedLeft);
    }
}
```

方法名可以用中文（或用 `@DisplayName`），测试报告可读性很好。
lang-basics 中的真实例子：[MoneyTest.java](../code/lang-basics/src/test/java/study/basics/MoneyTest.java)、
[ShapesTest.java](../code/lang-basics/src/test/java/study/basics/ShapesTest.java)。

## 3. Mockito

```java
@ExtendWith(MockitoExtension.class)
class OrderServiceMockTest {

    @Mock ProductRepository products;
    @Mock OrderRepository orders;
    @Mock ShopProperties properties;
    @InjectMocks OrderService service;

    @Test
    void 下单时扣减库存并保存订单() {
        var phone = new Product("PHONE-1", "手机", new BigDecimal("1999.00"), 10);
        given(properties.maxOrderItems()).willReturn(20);
        given(products.findById(1L)).willReturn(Optional.of(phone));
        given(orders.save(any(Order.class))).willAnswer(inv -> inv.getArgument(0));

        var request = new PlaceOrderRequest("ben",
                List.of(new PlaceOrderRequest.OrderLine(1L, 2)));
        OrderResponse response = service.place(request);

        assertThat(phone.getStock()).isEqualTo(8);
        assertThat(response.total()).isEqualByComparingTo("3998.00");
        verify(orders).save(argThat(o -> o.getItems().size() == 1));
    }
}
```

| Mockery | Mockito |
|---|---|
| `$m->shouldReceive('find')->with(1)->andReturn($p)` | `when(m.findById(1L)).thenReturn(Optional.of(p))` |
| `->once()` | `verify(m, times(1)).findById(1L)` |
| `->andThrow(...)` | `thenThrow(...)` |
| `Mockery::on(fn...)` | `argThat(...)` |

## 4. 切片测试：只启动需要的那部分 Spring

| 注解 | 启动内容 | 用途 |
|---|---|---|
| `@WebMvcTest(XxxController.class)` | MVC 层（Controller、Advice、Filter、Jackson），不含 Service/DB | 测路由、参数校验、JSON 格式、状态码 |
| `@DataJpaTest` | JPA + 数据源 + Flyway，每个测试结束后回滚 | 测 Repository 查询、映射 |
| `@JsonTest` | 只有 Jackson | 测序列化格式 |
| `@SpringBootTest` | 完整容器 | 端到端集成测试 |

```java
@WebMvcTest(ProductController.class)
@Import(SecurityConfig.class)
class ProductControllerTest {

    @Autowired MockMvc mvc;
    @MockitoBean ProductService products;

    @Test
    void 参数非法返回400() throws Exception {
        mvc.perform(post("/api/products")
                        .with(user("admin").roles("ADMIN"))
                        .contentType(MediaType.APPLICATION_JSON)
                        .content("""
                                {"sku": "", "name": "", "price": -1, "stock": 1}
                                """))
                .andExpect(status().isBadRequest())
                .andExpect(jsonPath("$.errors.sku").exists())
                .andExpect(jsonPath("$.errors.price").exists());
    }

    @Test
    void 查询商品() throws Exception {
        var product = new Product("PHONE-1", "手机", new BigDecimal("1999.00"), 10);
        given(products.get(1L)).willReturn(product);

        mvc.perform(get("/api/products/1"))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.sku").value("PHONE-1"));
    }
}
```

真实实现见 [ProductControllerTest.java](../code/shop-api/src/test/java/study/shop/product/ProductControllerTest.java)：
它还覆盖了 401（未认证）、403（普通用户删除）、201 + `Location` 等场景。
Spring Boot 4 中 `@WebMvcTest` 的包名变为 `org.springframework.boot.webmvc.test.autoconfigure.WebMvcTest`。

## 5. 用真实数据库测试：Testcontainers

H2 内存库和 PostgreSQL / MySQL 方言不同（JSONB、窗口函数、锁行为），**Repository 和迁移脚本应该在真实数据库上测**。Testcontainers 会用 Docker 临时启动一个数据库容器：

```java
@Tag("testcontainers")
@Testcontainers(disabledWithoutDocker = true)
@SpringBootTest
@ActiveProfiles("test")
class PostgresTestcontainersTest {

    @Container
    static final PostgreSQLContainer POSTGRES =
            new PostgreSQLContainer("postgres:17-alpine");   // Testcontainers 2.x 中不是泛型类

    @DynamicPropertySource
    static void datasource(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", POSTGRES::getJdbcUrl);
        registry.add("spring.datasource.username", POSTGRES::getUsername);
        registry.add("spring.datasource.password", POSTGRES::getPassword);
        registry.add("spring.datasource.driver-class-name", POSTGRES::getDriverClassName);
    }

    @Autowired ProductRepository repo;

    @Test
    void PostgreSQL 上 Flyway 迁移和读写正常() {
        var saved = repo.save(new Product("A", "a", BigDecimal.ONE, 3));
        assertThat(repo.findBySku("A")).isPresent();
    }
}
```

真实实现见 [PostgresTestcontainersTest.java](../code/shop-api/src/test/java/study/shop/PostgresTestcontainersTest.java)。
`@DynamicPropertySource` 的优先级高于 `application-test.yml` 里的 H2 URL，因此同一个测试类会连到容器。
Spring Boot 也支持 `@ServiceConnection` 自动注入连接信息，写法更短（适合不覆盖 `spring.datasource.url` 的测试）：

```java
@TestConfiguration(proxyBeanMethods = false)
class TestcontainersConfig {
    @Bean @ServiceConnection
    PostgreSQLContainer postgres() { return new PostgreSQLContainer("postgres:17-alpine"); }
}

public class TestShopApplication {
    public static void main(String[] args) {
        SpringApplication.from(ShopApiApplication::main).with(TestcontainersConfig.class).run(args);
    }
}
```

Testcontainers 2.x 中 PostgreSQL 模块的类位于 `org.testcontainers.postgresql` 包，Maven 坐标为 `org.testcontainers:testcontainers-postgresql`（JUnit 5 集成是 `testcontainers-junit-jupiter`）。

另外，项目根目录已有 [compose.yaml](../code/shop-api/compose.yaml)；本项目通过 `--spring.profiles.active=postgres` 连接它。
如果引入 `spring-boot-docker-compose` 依赖，`spring-boot:run` 也可以自动启动 compose 服务 —— 但这会让每次启动都依赖 Docker，默认 H2 模式反而不需要。

## 6. 测试金字塔建议

- 领域逻辑：大量纯单元测试（毫秒级）。
- Controller：`@WebMvcTest` 覆盖校验、错误码、JSON 契约。
- Repository：`@DataJpaTest` + Testcontainers，只测自定义查询。
- 少量 `@SpringBootTest` 端到端：下单主流程、安全配置。

`@SpringBootTest` 启动整个容器比较慢，Spring 会 **缓存测试上下文**：配置相同的测试类共享一个容器。滥用 `@MockitoBean` 会让每个测试类的上下文都不同、导致反复启动 —— 这是 Java 项目测试变慢的常见原因。
