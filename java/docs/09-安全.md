## 1. 概念映射

| Laravel | Spring Security |
|---|---|
| `auth` 中间件 | `SecurityFilterChain`（一组 Servlet Filter） |
| Guard（session / sanctum / passport） | 认证机制（表单登录、HTTP Basic、OAuth2 Resource Server…） |
| `Auth::user()` | `SecurityContextHolder.getContext().getAuthentication()` / `@AuthenticationPrincipal` |
| User Provider | `UserDetailsService` |
| `Hash::make()` | `PasswordEncoder`（BCrypt / Argon2） |
| Gate / Policy | `@PreAuthorize` + 自定义授权 Bean |
| `can:` 中间件 | `authorizeHttpRequests` 规则 |
| `VerifyCsrfToken` | 内置 CSRF 防护（无状态 API 通常关闭） |
| Sanctum / Passport | OAuth2 Resource Server（JWT 校验）/ Spring Authorization Server |

引入 `spring-boot-starter-security` 后，**所有接口默认需要认证**（自动生成一个随机密码的用户）—— 默认安全，然后由你放开。

## 2. 一个典型的无状态 JWT API 配置

```java
@Configuration
@EnableMethodSecurity                                   // 启用 @PreAuthorize
public class SecurityConfig {

    @Bean
    SecurityFilterChain api(HttpSecurity http) throws Exception {
        http
            .csrf(csrf -> csrf.disable())               // 纯 Token API、无 Cookie 会话时可以关闭
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/actuator/health/**").permitAll()
                .requestMatchers(HttpMethod.GET, "/api/products/**").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated())
            .oauth2ResourceServer(o -> o.jwt(Customizer.withDefaults()));   // 校验 Bearer JWT
        return http.build();
    }
}
```

```yaml
spring:
  security:
    oauth2:
      resourceserver:
        jwt:
          issuer-uri: https://auth.example.com/realms/shop   # 自动拉取 JWKS 公钥验签
```

Token 由独立的认证服务签发（Keycloak、Auth0、Spring Authorization Server、或你已有的 PHP 用户中心），Spring 应用只做 **资源服务器**：验签、校验过期、解析权限。这也是 PHP 系统和 Java 系统共存时打通登录态的标准做法。

## 3. 在业务代码中获取当前用户

```java
@GetMapping("/api/me/orders")
List<OrderResponse> myOrders(@AuthenticationPrincipal Jwt jwt) {
    String userId = jwt.getSubject();
    return orderService.listByUser(userId);
}
```

本质是 ThreadLocal（第 02 章），在 `@Async` 或自建线程池中默认拿不到。

## 4. 方法级授权 ≈ Policy

```java
@Service
public class OrderService {

    @PreAuthorize("hasRole('ADMIN') or @orderPolicy.isOwner(#orderId, authentication)")
    public OrderResponse get(Long orderId) { ... }
}

@Component("orderPolicy")
class OrderPolicy {
    private final OrderRepository orders;
    OrderPolicy(OrderRepository orders) { this.orders = orders; }

    public boolean isOwner(Long orderId, Authentication auth) {
        return orders.findOwnerId(orderId).map(auth.getName()::equals).orElse(false);
    }
}
```

`@PreAuthorize` 同样基于代理（第 07 章），同类内部调用不生效。

## 5. 传统 Session 登录

后台管理系统等需要服务端会话时：

```java
http.formLogin(Customizer.withDefaults())
    .logout(Customizer.withDefaults());
```

多实例部署需要共享 Session：引入 `spring-session-data-redis`，与 Laravel 用 Redis 作 session driver 相同。

## 6. 密码存储

```java
@Bean
PasswordEncoder passwordEncoder() {
    return PasswordEncoderFactories.createDelegatingPasswordEncoder();   // 默认 bcrypt，存储为 {bcrypt}$2a$...
}
```

迁移 PHP 用户库时：PHP `password_hash()` 生成的 `$2y$` BCrypt 哈希可以被 Spring 的 `BCryptPasswordEncoder` 校验（`$2y$` 与 `$2a$`/`$2b$` 兼容），用户无需重置密码。

## 7. 测试安全配置

```java
@WebMvcTest(ProductController.class)
@Import(SecurityConfig.class)
class ProductSecurityTest {
    @Autowired MockMvc mvc;
    @MockitoBean ProductService products;

    @Test
    void 未登录写入返回401() throws Exception {
        mvc.perform(post("/api/products")
                        .contentType(MediaType.APPLICATION_JSON)
                        .content("""{"sku":"X","name":"x","price":1,"stock":1}"""))
           .andExpect(status().isUnauthorized());
    }

    @Test
    void 普通用户删除返回403() throws Exception {
        mvc.perform(delete("/api/products/1").with(user("u").roles("CUSTOMER")))
           .andExpect(status().isForbidden());
    }
}
```

需要 `spring-security-test` 依赖（Boot 4 中可用 `spring-boot-starter-security-test`）。
真实测试见 [ProductControllerTest.java](../code/shop-api/src/test/java/study/shop/product/ProductControllerTest.java) 与
[ShopApiApplicationTest.java](../code/shop-api/src/test/java/study/shop/ShopApiApplicationTest.java)
（后者用 `httpBasic("admin", "admin123")` 走完整过滤器链）。
