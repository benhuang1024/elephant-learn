| 用途 | PHP | Java |

## 安装 JDK 25

推荐 SDKMAN，可以像 phpenv 一样在多个 JDK 间切换：

```bash
curl -s "https://get.sdkman.io" | bash
```

```bash
sdk install java 25-tem
```

或者用 Homebrew：

```bash
brew install openjdk@25
```

验证：

```bash
java -version
```

> **JDK 发行版**：OpenJDK 有很多“发行版”（Temurin、Corretto、Zulu、Oracle JDK、GraalVM），代码是同一套，区别在于构建者和支持策略。不确定就用 **Eclipse Temurin**。
>
> **LTS**：Java 每半年发一个版本，每两年一个 LTS（17 → 21 → 25）。生产环境只选 LTS。

## php-fpm vs JVM：先换掉“进程模型”的直觉

| | PHP-FPM | Spring Boot / JVM |
|---|---|---|
| 进程 | 每个请求由 FPM 分配一个 worker，请求结束内存基本释放 | **一个常驻 JVM**，启动时加载类、建立连接池，之后一直复用 |
| 并发 | 多进程，进程间不共享内存（share-nothing） | 一个进程内多线程，**共享堆上的对象** |
| 状态 | 请求级全局变量、静态变量随请求结束消失 | 单例 Bean 的字段、静态变量会被所有请求共享 |
| 部署 | 换代码 + reload | 重启进程；启动要几秒到几十秒 |
| 内存 | 按 worker 估算 | 堆 + Metaspace + 线程栈 + 直接内存 |

由此产生两条最重要的规矩：

1. **单例 Bean 必须无状态**。需要请求级数据就放在方法参数或局部变量里，绝不能写进单例字段。
2. **共享可变状态必须同步**（`Atomic*`、`synchronized`、并发容器，或干脆不可变）。

第 02 章会用代码演示竞态；第 04 章会演示“单例里存用户信息”为什么是事故。

## 第一个程序：像 PHP 一样直接跑

Java 25 起可以不写 `class`、不写 `public static void main`，直接运行单文件：

```java
// Hello.java
void main() {
    IO.println("Hello, PHPer");
}
```

```bash
java Hello.java
```

示例见 [scripts/Hello.java](../code/lang-basics/scripts/Hello.java)。这只适合写脚本；正式项目一定是 Maven 工程 + 包结构。

## 编译型语言的工作流

PHP：改代码 → 刷新浏览器。
Java：改代码 → **编译**（javac 把 `.java` 编译成 `.class` 字节码）→ JVM 加载运行。

日常开发中你几乎感受不到编译：

- IntelliJ 保存即增量编译；
- Spring Boot DevTools 检测到 class 变化会自动重启应用（1～2 秒）；
- 写业务逻辑时更多是 **跑单元测试** 而不是重启服务验证。

编译带来的回报：重命名一个方法，IDE 能 100% 正确地改完所有调用方；PHPStan level 9 能做到的，Java 编译器默认就做到了。

## 用 Spring Initializr 生成项目

打开 [start.spring.io](https://start.spring.io)，选择：

- Project: **Maven**，Language: **Java**，Spring Boot: **4.1.x**
- Java: **25**，Packaging: **Jar**（不要选 War）
- Dependencies：`Spring Web`、`Validation`、`Spring Data JPA`、`Flyway Migration`、`PostgreSQL Driver`、`H2 Database`、`Spring Security`、`Spring Boot Actuator`、`Spring Boot DevTools`

下载解压后得到：

```
demo/
├── mvnw, mvnw.cmd, .mvn/          # Maven Wrapper：锁定 Maven 版本，类似 vendor/bin 里的工具
├── pom.xml                        # ≈ composer.json
└── src/
    ├── main/
    │   ├── java/com/example/demo/
    │   │   └── DemoApplication.java   # ≈ public/index.php + bootstrap/app.php
    │   └── resources/
    │       ├── application.yml        # ≈ config/*.php + .env
    │       ├── static/                # ≈ public/ 下的静态文件
    │       └── db/migration/          # Flyway 迁移脚本 ≈ database/migrations
    └── test/java/...                  # ≈ tests/
```

常用命令：

| 目的 | PHP / Laravel | Maven |
|---|---|---|
| 安装依赖 | `composer install` | 自动（首次构建时下载到 `~/.m2`） |
| 启动开发服务 | `php artisan serve` | `./mvnw spring-boot:run` |
| 跑测试 | `vendor/bin/phpunit` | `./mvnw test` |
| 打包部署 | 拷贝代码 + `composer install --no-dev` | `./mvnw package` → 一个可执行 jar |
| 运行产物 | php-fpm + nginx | `java -jar target/demo.jar` |

注意最后一行：Spring Boot 的产物是一个 **自带 Tomcat 的 fat jar**，不需要 nginx + php-fpm 这样的组合，`java -jar` 就是一个完整的 HTTP 服务（生产上前面一般仍会放 nginx / 网关做 TLS 和负载均衡）。
