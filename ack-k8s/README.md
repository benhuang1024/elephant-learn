# 阿里云 ACK 与 Kubernetes：用“集装箱港口”讲给小学生听

> 目标：先把 **Kubernetes（K8s）和阿里云 ACK（容器服务 Kubernetes 版）** 自己学透，再用**类比**讲给小学生听；最后能在 ACK 上真正部署 **Spring Boot** 和 **Magento**。
> 用法：每章都分两层，**“讲给孩子听”**和**“大人要懂的真相”**。先读真相把自己讲明白，再照着故事讲给孩子。
> 事实核对日期：2026-10（ACK 的产品形态、版本、价格变化很快，动手前以[阿里云官方文档](https://help.aliyun.com/zh/ack/)为准）。

## 一张图看懂整套类比

整本教材只用**一个**类比：**集装箱港口**。名字本身就是线索：Kubernetes 在希腊语里是“舵手”，Docker 的标志是一头驮着集装箱的鲸鱼。

```
                       ┌──────────── 港口（集群 Cluster）────────────┐
  你（下订单的人）       │                                             │
     │  kubectl          │   ┌──────── 港口调度中心（控制面）──────┐   │
     └─────────────────► │   │ 服务窗口 API Server                │   │
                         │   │ 总账本 etcd                        │   │
                         │   │ 调度员 Scheduler                   │   │
                         │   │ 巡查员 Controller                  │   │
                         │   └────────────────────────────────────┘   │
                         │        ▲ ACK：阿里云替你开好、管好调度中心    │
                         │                                             │
                         │   场地 1（节点 Node）    场地 2（节点 Node）    │
                         │   管理员 kubelet         管理员 kubelet        │
                         │   [托盘Pod][托盘Pod]     [托盘Pod]             │
                         │                                             │
                         │   取货窗口 Service      港口大门导航牌 Ingress   │
                         └─────────────────────────────────────────────┘
  设计图档案馆（镜像仓库 ACR）：每个集装箱都照这里的设计图装
```

## 两条学习路径

### 路径 A：自己学透（约 2 周，每天 1 小时）
1. **第 1–3 天**：读 01–03，重点是把 03 里“下一个订单之后发生了什么”的流程自己默写出来。
2. **第 4–6 天**：读 04–06，每读一个对象，就去附录的对照表里找到它的类比，再用自己的话讲一遍。
3. **第 7–8 天**：读 07，然后做 08 的实验。**实验结束当天一定要删集群**，不然会持续扣费。
4. **第 9 天**：读 09，对照 [security/03-infra-cloud/kubernetes-security.md](../security/03-infra-cloud/kubernetes-security.md) 想一想生产环境还缺什么。
5. **第 10–14 天**：做 13（Spring Boot），再做 14（Magento）。

### 路径 B：备课（读完路径 A 之后）
1. 读 00，记住“讲类比的 5 条原则”。
2. 从 10 里选一个教案，把用到的章节只读“港口故事”和“低年级简化版”两部分，大声念一遍。
3. 读 11，把孩子可能问的问题过一遍，特别是“类比哪里不像”这一节。
4. 课后用 12 的学生小测检查效果。

## 核心心法（先记住这 10 句）

1. **容器 = 集装箱**：不管里面装的是什么程序，外面的“箱子”都是标准的，所以哪台机器都能运。
2. **镜像是设计图，容器是照着设计图装好的箱子**。一张图可以装出很多个一模一样的箱子。
3. **Kubernetes 是港口调度中心**：你只说“我要什么”，它负责“放在哪、坏了换、忙了加”。
4. **你写的是“期望”，不是“步骤”**：说“永远保持 3 个托盘”，而不是“去 2 号场地放一个托盘”。
5. **巡查员永远在核对账本**：账本上写 3 个，实际只有 2 个，它就马上补 1 个。这就是“自愈”。
6. **托盘（Pod）随时会被换掉，所以要有固定的取货窗口（Service）**。
7. **集装箱里的东西默认是临时的**：箱子一换，里面的东西就没了。要长期保存的东西必须放进仓库（持久卷）。
8. **ACK = 阿里云替你开好、管好调度中心**：你只管租场地、下订单。
9. **云上的东西按时间收费**：做完实验就拆掉。
10. **每个类比都有不像的地方**：讲完类比，一定要告诉孩子“这里不像”。
