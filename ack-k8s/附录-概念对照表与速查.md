## 3. kubectl 速查

```bash
# 看
kubectl get nodes -o wide
kubectl get pods -A                               # 所有命名空间
kubectl -n shop get deploy,rs,pods,svc,ingress,pvc
kubectl get pods -l app=shop-api -o wide          # 按标签
kubectl describe pod <pod>                        # 排障第一步：看最下面的 Events
kubectl get events -A --sort-by=.lastTimestamp
kubectl top nodes; kubectl top pods -A

# 日志与进入容器
kubectl logs <pod> [-c 容器名] [--previous] [-f]
kubectl logs deploy/<name> --tail=100
kubectl exec -it <pod> [-c 容器名] -- sh
kubectl port-forward svc/<svc> 8080:80
kubectl cp <pod>:/path/file ./file

# 改
kubectl apply -f file.yaml        # 声明式（推荐）
kubectl apply -k dir/             # kustomize 目录
kubectl diff -k dir/              # 应用之前先看会改什么
kubectl delete -f file.yaml
kubectl scale deploy/<name> --replicas=3
kubectl set image deploy/<name> <容器>=<镜像>
kubectl rollout status|history|undo deploy/<name>
kubectl rollout restart deploy/<name>             # 重启所有 Pod（比如 Secret 改了以后）

# 节点维护
kubectl cordon <node>; kubectl drain <node> --ignore-daemonsets --delete-emptydir-data; kubectl uncordon <node>

# 查文档（离线也能用）
kubectl explain deployment.spec.strategy
kubectl api-resources
```

## 4. ACK 控制台速查

| 想做的事 | 在哪里 |
|---|---|
| 拿 kubeconfig | 集群详情 → 连接信息 |
| 加节点 / 改节点规格 | 集群 → 节点管理 → 节点池 |
| 装组件（ALB Ingress、Virtual Node、CNFS 等） | 集群 → 运维管理 → 组件管理 |
| 给 RAM 用户授权 | 容器服务控制台 → 授权管理 |
| 看日志 / 监控 | 集群 → 运维管理 → 日志中心 / Prometheus 监控 |
| 升级集群 | 集群 → 集群信息 → 升级（先升控制面，再升节点池） |
| 看费用 | 成本套件（成本洞察），以及费用中心按标签统计 |
