怎么用这套学堂

给已经有十年 PHP 架构经验的人，不是给初学者。

01

先做映射，别重学

HTTP、REST、ORM、DI、事务、缓存、队列你已经懂了。教材里这些只做对照映射，一眼扫过即可。真正要停下来的是运行模型和类型系统。

02

把「反直觉」当成清单

每章末尾的「一句话对照表」和自测题，就是 PHP 直觉失效点的清单。答不上来的那一条，回到对应实验台跑一遍。

03

对照着读三套代码

java / python / typescript 的 shop-api 是同一套业务：同样的接口、同样的演示账号、同样的 409 problem+json、同样的乐观锁。差异只可能来自语言本身。

04

笔记写给三个月后的自己

每章右下角「写笔记」，存在本机浏览器里，可一键导出 Markdown。用自己的话复述一遍，才算真的学会。
