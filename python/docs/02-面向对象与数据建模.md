PHP 8 的类已经很现代；Python 的差异主要在 **`self` 显式传递、魔术方法协议、Protocol 结构化类型、多继承 MRO**。本章只讲这些差异，以及如何选择 `dataclass` / `NamedTuple` / `Enum` / `Protocol`。

## 1. 类与实例

```python
class Product:
    category = "goods"            # 类属性，所有实例共享

    def __init__(self, sku: str, stock: int) -> None:
        self.sku = sku            # 实例属性
        self.stock = stock

    def deduct(self, quantity: int) -> None:
        if quantity > self.stock:
            raise ValueError("库存不足")
        self.stock -= quantity

    def __str__(self) -> str:
        return f"Product({self.sku}, stock={self.stock})"
```

| PHP | Python |
|---|---|
| `$this->sku` | `self.sku` |
| `__construct` | `__init__` |
| `public/private/protected` | 只有命名约定：`_internal`、`__mangled` |
| `__toString()` | `__str__()` |
| `readonly` 属性 | `frozen dataclass` / `@property` |
| `final class` | 无关键字；靠约定/`typing.final` 检查 |
| `interface` | `Protocol`（结构化）或 `ABC`（名义） |
| `trait` | mixin 多继承（谨慎） |

Python 没有真正的访问控制。`_name` 表示内部使用，`__name` 会被改写（name mangling），但都能绕过。**不要用 getter/setter 包住所有字段**，先设计好不可变边界。

## 2. 魔术方法 ≈ PHP 魔术方法

| 魔术方法 | 触发场景 | PHP 类比 |
|---|---|---|
| `__init__` | 构造 | `__construct` |
| `__str__` / `__repr__` | `str()` / 调试 | `__toString` |
| `__eq__` | `==` | 自定义相等（PHP 较难） |
| `__hash__` | `hash()`、set/dict 键 | — |
| `__len__` | `len(x)` | `Countable` |
| `__iter__` / `__next__` | `for` | `Iterator` |
| `__enter__` / `__exit__` | `with` | — |
| `__add__` / `__mul__` | 运算符 | 无直接对应 |
| `__call__` | 实例当函数调用 | `__invoke` |
| `__getattr__` | 属性缺失时 | `__get` |

`__repr__` 应返回可调试、尽量可重建的字符串；`__str__` 面向人类。

## 3. dataclass：DTO / 值对象的默认答案

```python
from dataclasses import dataclass, field
from decimal import Decimal

@dataclass(frozen=True, slots=True)
class Money:
    amount: Decimal
    currency: str = "CNY"
```

`@dataclass` 自动生成 `__init__`、`__repr__`、`__eq__`。选项：

| 参数 | 作用 |
|---|---|
| `frozen=True` | 不可变，赋值抛 `FrozenInstanceError`；可哈希 |
| `slots=True` | 限制属性、减少内存 |
| `order=True` | 生成 `<` `>`（要有明确排序语义才用） |
| `kw_only=True` | 所有字段仅关键字，避免位置参数误用 |
| `field(default_factory=list)` | 可变默认值 |

与 PHP 的对应：

```php
final readonly class Money {
    public function __construct(
        public Decimal $amount,
        public string $currency = 'CNY',
    ) {}
}
```

### 值对象要点

- 金额/币种、邮箱、手机号、订单号适合做值对象。
- 在 `__post_init__` 里校验和归一化（见 [money.py](../code/lang-basics/src/basics/money.py)）。
- 运算方法返回新对象，不修改自身。
- 不要给值对象加数据库/HTTP 依赖。

## 4. NamedTuple 与普通 tuple

```python
from typing import NamedTuple

class Point(NamedTuple):
    x: float
    y: float

point = Point(1.0, 2.0)
point.x          # 1.0
x, y = point     # 可解包
```

适合“轻量、不可变、需要解包”的返回值。需要校验/方法较多时用 dataclass。

## 5. Enum / StrEnum

```python
from enum import StrEnum

class OrderStatus(StrEnum):
    PENDING = "PENDING"
    PAID = "PAID"
    CANCELLED = "CANCELLED"
```

与 PHP 8.1 backed enum 几乎一样：

```php
enum OrderStatus: string {
    case PENDING = 'PENDING';
    case PAID = 'PAID';
    case CANCELLED = 'CANCELLED';
}
```

- `StrEnum` 成员是字符串，可以直接 JSON 序列化、写数据库。
- `OrderStatus("PAID")` 从字符串解析，非法值抛 `ValueError`。
- 状态流转规则集中放模块常量（见 [order_status.py](../code/lang-basics/src/basics/order_status.py)），不要散落在 Service。
- 用 `match` + `assert_never`（`typing`）让新增状态时静态检查报错。

普通 `Enum` 的 `str()` 默认是 `OrderStatus.PAID`；`StrEnum` 是 `PAID`。API 里几乎总是想要后者。

## 6. Protocol：结构化子类型

PHP 的 interface 是名义类型：必须 `implements`。Python 的 `Protocol` 只看“形状”：

```python
from typing import Protocol

class Shape(Protocol):
    def area(self) -> float: ...

@dataclass(frozen=True)
class Circle:
    radius: float

    def area(self) -> float:
        return 3.14159 * self.radius ** 2

def total_area(shapes: list[Shape]) -> float:
    return sum(shape.area() for shape in shapes)
```

`Circle` 没有继承 `Shape`，但 mypy 认可它；`total_area([Circle(1)])` 合法。这就是“鸭子类型 + 静态检查”。

- 需要 `isinstance(x, Shape)` 时加 `@runtime_checkable`；只检查方法名存在，不检查签名。
- Protocol 适合“消费者定义的接口”（依赖倒置），库作者定义接口时也可以用。
- 需要共享实现（模板方法）时用 ABC。

### ABC（抽象基类）

```python
from abc import ABC, abstractmethod

class PaymentGateway(ABC):
    @abstractmethod
    def charge(self, amount: Decimal) -> str: ...
```

ABC 是名义继承，实例化未实现抽象方法的子类会报错。Protocol 更轻，ABC 更适合提供公共实现。

## 7. 多继承与 MRO vs trait

```python
class TimestampMixin:
    created_at: datetime

class SoftDeleteMixin:
    deleted_at: datetime | None = None

class Order(TimestampMixin, SoftDeleteMixin):
    ...
```

- Python 支持多继承，方法解析顺序是 **C3 线性化**（`Order.__mro__` 可查看）。
- mixin 应是“小、无状态、可组合”的；不要用多继承做业务分类。
- 与 PHP trait 的差异：trait 是编译期复制方法，Python 是真正的继承链；`super()` 会沿 MRO 继续调用。
- 菱形继承时 `super().__init__()` 的协作式初始化容易出错；优先组合。

```python
# 组合优先
class OrderService:
    def __init__(self, orders: OrderRepository, clock: Clock) -> None:
        self.orders = orders
        self.clock = clock
```

## 8. 属性与封装

```python
class Product:
    def __init__(self, stock: int) -> None:
        self._stock = stock

    @property
    def stock(self) -> int:
        return self._stock

    @stock.setter
    def stock(self, value: int) -> None:
        if value < 0:
            raise ValueError("库存不能为负")
        self._stock = value
```

`@property` ≈ PHP 的 getter + 计算属性，但调用处不变（`product.stock`，不是 `product.getStock()`）。

- 只读计算属性用 `@property`，不要加 setter。
- 需要缓存的计算属性用 `functools.cached_property`（要求实例有 `__dict__`，slots 类不行）。
- 真正的不可变用 frozen dataclass。

## 9. 继承、`super()` 与构造

```python
class BaseRepository:
    def __init__(self, session: Session) -> None:
        self.session = session

class ProductRepository(BaseRepository):
    def __init__(self, session: Session) -> None:
        super().__init__(session)
```

- Python 3 的 `super()` 不需要参数。
- 子类 `__init__` 不会自动调用父类；必须显式。
- 方法重写不需要注解；类型检查器会检查签名兼容性（参数逆变、返回值协变）。

## 10. 数据建模选择表

| 需求 | 选择 | 原因 |
|---|---|---|
| DTO / 值对象 | `@dataclass(frozen=True, slots=True)` | 自动生成、可比较、可哈希 |
| 轻量返回值 | `NamedTuple` | 可解包、零开销 |
| 固定选项/状态 | `StrEnum` / `Enum` | 类型安全、可序列化 |
| 消费者定义的接口 | `Protocol` | 解耦、无继承侵入 |
| 需要公共实现 | `ABC` | 模板方法、强制实现 |
| 可复用横切行为 | mixin / 装饰器 | 小而无状态 |
| ORM 实体 | 框架的声明式基类 | 见 [08 章](08-数据访问与事务.md) |

## 11. `__eq__` 与 `__hash__` 的陷阱

```python
@dataclass
class MutableItem:
    name: str
```

dataclass 默认生成 `__eq__`；如果 `eq=True` 且 `frozen=False`，`__hash__` 被设为 `None`，对象不能当 dict 键。这正是“可变对象不该做哈希键”的语言级提醒。

- 值对象：`frozen=True`，可安全做键。
- 实体（有 id）：相等通常按 id，且不要用整个对象做缓存键；用 id。
